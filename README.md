# 🏃 Garmin Dashboard

> Automated fitness analytics pipeline: send a CSV from Garmin Connect to Telegram → Claude AI analyzes it → PostgreSQL stores it → Power BI visualizes it.

## Architecture

```
📱 Garmin Connect
      │  Export CSV (manual)
      ▼
💬 Telegram Bot
      │  Send CSV file
      ▼
⚙️  n8n (webhook workflow)
      │  Download file → call analyzer
      ▼
🤖 FastAPI + Claude API
      │  Tool-use: parse & normalize activities
      ▼
🐘 PostgreSQL (Azure VM)
      │  Upsert with dedup (ON CONFLICT DO NOTHING)
      ▼
📊 Power BI Desktop
      │  Live connection via Tailscale VPN
      └─ 4-page dashboard
```

---

## Features

- **One-step deploy** — `bash scripts/deploy.sh` sets up everything on a fresh Ubuntu VM
- **Claude AI analysis** — uses Tool Use API to guarantee schema-valid JSON output
- **Smart dedup** — re-sending the same CSV never creates duplicate rows
- **Hebrew Telegram replies** — summary with stats sent back after each upload
- **Secure remote DB** — Power BI connects to PostgreSQL over Tailscale (no open ports)
- **Auto SSL renewal** — Let's Encrypt cert renewed monthly via cron

## Stack

| Layer | Technology |
|---|---|
| AI Analysis | [Claude API](https://anthropic.com) — `claude-sonnet-4-6` with Tool Use |
| Workflow | [n8n](https://n8n.io) — webhook mode, 8 nodes |
| API | FastAPI (Python) — `/process` + `/health` endpoints |
| Database | PostgreSQL 15 — `activities` table with UNIQUE constraint |
| Reverse proxy | nginx + Let's Encrypt SSL |
| Infrastructure | Azure VM (Ubuntu 22.04) + Docker Compose |
| Remote access | Tailscale VPN |
| Visualization | Power BI Desktop — 4 pages, 6 DAX measures |

## Quick Start

### Prerequisites
- Azure VM (Standard_B2s or higher, Ubuntu 22.04)
- Domain / Azure FQDN pointing to VM IP
- Telegram bot token (from [@BotFather](https://t.me/BotFather))
- Anthropic API key

### Deploy

```bash
# 1. Clone on the VM
git clone https://github.com/TalYanai/garmin-dashboard.git
cd garmin-dashboard

# 2. Configure environment
cp .env.example .env
nano .env   # fill in your values

# 3. One-shot deploy (Docker, SSL, all services)
bash scripts/deploy.sh
```

### Load historical data

```bash
# Copy your Garmin CSV export to the VM, then:
docker compose run --rm \
  -v $(pwd)/Activities.csv:/data/Activities.csv \
  analyzer \
  python initial_load.py /data/Activities.csv
```

### Connect Power BI

1. Install [Tailscale](https://tailscale.com) on both VM and local machine
2. Get VM's Tailscale IP: `tailscale ip -4`
3. Power BI → Get Data → PostgreSQL → `<tailscale-ip>:5432` / database: `garmin`
4. See `powerbi/README.md` for DAX measures and dashboard setup

## How It Works

1. **Export** your activities from [Garmin Connect](https://connect.garmin.com) → All Activities → Export CSV
2. **Send** the CSV file to your Telegram bot
3. **n8n** receives it via webhook, downloads the file, calls the FastAPI analyzer
4. **FastAPI** sends the CSV to Claude API with a `save_activities` tool — Claude extracts and normalizes all activities (unit conversions: miles→km, ft→m, HH:MM:SS→minutes)
5. **PostgreSQL** upserts the activities — duplicate rows are silently ignored
6. **Telegram** bot replies with a Hebrew summary (count, distance, avg HR, calories, breakdown by type)
7. **Power BI** — hit Refresh to see the new data in the dashboard
